# OpenVLA + FAIRINO Pick-and-Place

This repository contains the validated real-robot pipeline used to perform a
top-right can pick-and-place task with a FAIRINO robot, a RealSense D455 camera,
OpenVLA inference, depth-based object localization, and a DH gripper.

## System overview

```text
Live D455 RGB
    ↓
OpenVLA 7D action inference
    ↓
RT-DETR object detection + D455 depth
    ↓
Stable object position in the FAIRINO base frame
    ↓
Read-only hardware and workspace preflight
    ↓
Safety-constrained FAIRINO pick-and-place
```

OpenVLA is executed on the live RGB observation and produces a valid 7D action.
The final grasp and placement trajectory in this version is generated by the
depth-based safety planner rather than by a closed-loop OpenVLA rollout.

## Repository files

### `run_openvla_existing_pick_pipeline_dryrun.py`

Read-only runtime generator.

It performs:

- D455 RGB/depth acquisition
- object detection
- multi-sample object-position stability validation
- OpenVLA inference using the live RGB frame and instruction
- grasp/place target generation
- finite-value and workspace checks
- creation of `openvla_pick_runtime.json`

It must not send robot or gripper commands.

### `preflight_openvla_pick_place_readonly.py`

Final read-only GO/NO-GO checker.

It validates:

- required files
- runtime freshness
- expected instruction
- OpenVLA 7D action shape and finite values
- detected, grasp, and place targets
- calibrated workspace
- emergency stop and safety stop
- robot errors and safety code
- Tool/User frame
- current TCP and Observation-pose proximity
- DH gripper initialization, ready state, and open position

It must report all checks as PASS before live execution.

### `run_openvla_fairino_pick_place_live_v2.py`

Validated FAIRINO live execution program.

It performs:

- high-Z XY alignment
- continuous descent to grasp
- DH gripper close
- lift to a reachable transfer height
- top-right transfer
- controlled placement descent
- gripper release
- vertical retreat
- return to the Observation pose
- per-stage TCP tracking-error measurement

This file sends real robot and gripper commands.

### `dh_gripper.py`

DH gripper communication and position-control helper.

### `observation_pose.example.json`

Example schema and calibration values for the robot Observation pose.

Before execution, copy it to:

```text
observation_pose.json
```

and replace the values when using a different robot/tool/camera configuration.

### `can_workspace_calibration.example.json`

Example schema and calibrated object-workspace limits.

Before execution, copy it to:

```text
can_workspace_calibration.json
```

and recalibrate when the physical setup changes.

## Hardware used

- FAIRINO 6-axis robot
- FAIRINO controller at `192.168.58.2`
- Intel RealSense D455
- DH gripper
- NVIDIA Jetson AGX Thor
- Tool frame `1`
- User frame `0`

Device paths in the validated setup included:

```text
Camera     : /dev/video4
DH gripper : /dev/ttyUSB4
```

Check these paths on every computer.

## Environment

The validated Conda environment is:

```bash
conda activate openvla_py310
```

Model weights, the FAIRINO SDK, and system-specific drivers are not included.

## Setup

Clone the repository and create the local runtime configuration:

```bash
cp observation_pose.example.json observation_pose.json
cp can_workspace_calibration.example.json can_workspace_calibration.json
```

Verify source-code constants before use:

- robot IP
- camera device
- gripper serial port
- Tool/User frame
- model paths
- detector weights
- workspace limits
- grasp and placement heights
- velocity and override values

## Execution

### 1. Generate a fresh runtime target

```bash
python run_openvla_existing_pick_pipeline_dryrun.py \
  --camera /dev/video4 \
  --instruction "move the can to the top right" \
  --samples 20
```

Expected final status:

```text
FINAL RUNTIME TARGET RESULT: GO
NO ROBOT OR GRIPPER COMMAND SENT
```

### 2. Run the final read-only preflight

```bash
python preflight_openvla_pick_place_readonly.py
```

Do not continue unless every check passes and the final result is GO.

### 3. Execute the real pick-and-place task

```bash
python run_openvla_fairino_pick_place_live_v2.py
```

Keep the emergency-stop control immediately accessible and keep all people
outside the robot workspace.

## Safety

This repository controls a physical industrial robot.

Before every live run:

1. Verify the emergency stop and safety system.
2. Confirm that the robot is near the saved Observation pose.
3. Confirm Tool frame `1` and User frame `0`.
4. Confirm the TCP, gripper direction, and gripper open state.
5. Generate a fresh runtime file.
6. Require a complete read-only preflight PASS.
7. Ensure grasp, transfer, placement, retreat, and return paths are clear.
8. Stop immediately if abnormal sound, vibration, cable tension, or collision risk appears.

The included example calibration is not transferable to another setup without
verification.

## Validated result

The pipeline successfully completed a real can pick-and-place task and recorded
sub-millimeter TCP tracking errors during the executed motion stages.

A separate direct-action test also confirmed that a clamped OpenVLA Cartesian
action could be transmitted to the FAIRINO robot. That test is outside the
scope of this repository.

## Scope and limitations

Included:

- live OpenVLA inference
- RT-DETR/depth-based object localization
- FAIRINO and DH-gripper integration
- safety preflight
- successful real pick-and-place execution
- TCP tracking-error logging

Not included:

- closed-loop OpenVLA control of the complete task
- Concept Graph
- SimplerEnv
- simulation-to-real comparison
- pretrained model weights
- FAIRINO SDK distribution
